# 个人 API 与按需分析详情

用户明确要求各自在本机运行 Agent、配置自己的 API Key，并将工具记录、审查和导出等信息移出回答正文。本轮保留现有深色会话布局，扩展设置和详情功能，没有新增运行依赖。

## 交付

- 左侧“API 设置”填写兼容接口、模型和 Key，保存到当前系统用户的配置目录。Windows 使用 DPAPI；其他系统使用私密目录和 0600 文件。网页不回显 Key，不把 Key 放进浏览器持久存储或聊天记录。
- 保存只写本机配置。连接测试须主动点击，会发送一个不含业务数据的工具调用请求，界面明确可能计费；没有自动测试、自动接入或开发者 Key 回退。
- 工作台与 HTTP/SSE 问答均要求个人配置。每次分析使用独立的模型客户端和配置快照，修改在下次生效，执行中不会切换 Key。CLI/评测的显式 `build_agent(settings)` 仍可使用操作者自己的环境变量；工作台不走该回退。
- 正文只包含答案和“分析详情”按钮。运行时主区只显示简短状态；工具列表、审查、图表、结果表、来源、导出、保存时间和 SQL 示例操作都在按需打开的右侧面板中。历史使用同一布局；查看来源可以返回详情；关闭回到原回答，新建关闭旧详情。
- 本地 Compose 维持 127.0.0.1 端口发布，并显式允许对应桥接请求，将配置保存在专用本机卷。桥接模式仍限制回环 Host 和同源请求，不用于公网或多租户。这里只验证 Compose 语法与 ASGI 访问策略，没有重新构建或下载镜像。

## 验证与限制

`pytest`：436 项通过，94 项需要显式启用的集成测试跳过；`node --test tests/workspace.test.cjs`：45 项通过。Ruff、82 个源文件的 mypy、JavaScript 语法及 `git diff --check` 通过。

前端回归覆盖了正文/详情分离、未配置时保留草稿并打开设置、保存不测试模型、不在前端状态存储 Key、历史、来源与原有导出。后端覆盖本机加密/权限、配置重载/删除、跨源和远程拒绝、Docker 桥接边界、响应不含 Key、环境 Key 不回退、请求快照与客户端释放，以及 HTTP 完整 Agent 调用。

浏览器使用隔离 Chrome，真实鼠标与键盘，验证设置显示/隐藏、保存/清除/重载、显式测试连接、正文精简、右侧详情、E 编号、SQL 示例、来源回程、历史与停止。所有设置、连接测试、聊天、SQL 写入均为模拟响应；没有保存真实 Key、访问收费模型或写入用户业务数据。1440、1280、390、320px 无页面横向溢出；手机为视口模拟，不代表物理键盘或其他浏览器引擎验证。

原始记录、截图和静态检查位于 [验收目录](../../.impeccable/review/personal-api-details/)。静态检查不能解析服务端 `/assets/` 路径，所以默认 16px 标题告警不代表实际 CSS；隐藏的图片预览在有草稿后才设置来源。未添加忽略规则或声称检测零告警。

图片识别和 Embedding 仍使用安装者本机的独立配置，不继承聊天 Key。本轮不是多人服务器服务，没有用户账号或共享服务器数据隔离。真实模型连通性由使用者填写自己的 Key 后主动测试；自动验证全部离线。
