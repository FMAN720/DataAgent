# 核心分析优化验收

本轮按用户批准的优先顺序实现：程序化结果校验、可配置业务语义、可追踪及手动恢复的任务、跨场景回归集。保留已完成的个人 API 配置、Agent 对话布局、正文与详情分离、表格/文档/图片、历史及导出。

## 实现

- 数字与实际工具结果位置关联，使用已声明单位及 Decimal 核对；金额缩放、空值冒充零、比例及明确统计区间冲突会阻止可信写入。SQL 别名不当作已确认业务单位；部分验证和不适用明确区分。模型审查的一次修正也会收到程序反馈。
- 本机口径版本不可变，保存采用 compare-and-swap 和内容摘要。自定义模式支持单事实表求和、计数、均值、总分子/总分母比例，以及库存/余额单日快照约束。只开放当前口径及授权文档，实际字段和质量在只读快照内检查，筛选值采用参数绑定。
- 任务阶段、实际工具证据、尝试次数、最新结果保存至独立本机元数据文件；条件/口径变化、并发恢复和失效执行权会被拦截。恢复须用户确认、重新查询并参考上次校验反馈，没有自动付费重跑或复用旧数字。任务列表可在业务服务失联时读取；恢复执行仍需原数据及模型服务就绪。
- 21 个合成跨场景回归案例接入默认 pytest，覆盖金额单位、条件约束、库存、均值、计数、加权比例、未定义/真实零/无记录、数据质量、字段变更、注入值以及错误日期范围。脚本模型调用真实工具和编排，不是付费模型准确率评测。

详细使用、接口和约束见[核心分析指南](../../docs/core-analysis.md)。模板需按实际数据替换表与字段；保存检查定义格式，执行时检查数据映射。任意联表公式、跨调用全局快照、自动币种换算和更深统计工具属于后续优化范围。
