# 新手指南与可读性调整（2026-11-03）

本轮同时处理“完全没接触过也能使用”和“重点难捕捉、模块拥挤”的反馈，延续墨蓝/浅色视觉，不增加依赖。

## 界面变化

- 分析区收为最大 900px 的居中单列，取消重复欢迎大标题和右侧重复说明。数据管理入口仍在导航和提问框中。
- 输入与回答正文统一为 16px，放大主要说明、操作和结果明细字号，增加分区间距。正常周期拆解默认收起，口径不匹配时保持展开，异常提示没有隐藏。
- 首次访问只显示一条可跳过的邀请；右上角始终可打开“新手指南”。指南不是强制模态框，没有背景遮罩。
- 五步介绍演示体验、表格预览与导入、资料准备、提问条件、证据与历史/导出。操作可直达真实入口，但不会自动提交问题或选择文件。
- 跳过/完成只保存独立的浏览器本地状态；保留已有草稿、会话和正在进行的任务。存储受限时仍能开关指南，但刷新后可能再次邀请。Escape 优先关闭指南，回到可见入口。

## 验证

- 29 项前端测试通过：包括首次邀请、关闭/完成持久化、重看、步骤边界、无隐式 API 请求、草稿保护、忙碌/未启用状态、存储异常、焦点回程与异常拆解保持展开。
- 47 项相关 Python 测试通过，覆盖工作台、API 和图片核对；未新增后端逻辑或迁移。
- 实际 Chrome 精确视口覆盖 1440、1280、390 和 320px，页面无横向溢出、无运行时异常；引导在桌面及手机正常显示。首访、跳过后刷新、重看、实际上传入口、完成后回到提问均验证。
- 浏览器验收里的唯一聊天请求被拦截为明确标注的离线合成回复；没有调用外部模型或保存测试报告。
- 独立布局与新手体验审查：Ship，无必须修复项，见[审查记录](../../.impeccable/review/onboarding/review.md)。
- 布局机械检测未报告问题；该源码扫描器不能解析 FastAPI 的 `/assets/` 挂载路径，因此实际截图与浏览器溢出检查仍是布局依据，见[检测输出](../../.impeccable/review/onboarding/layout-detector.json)。
