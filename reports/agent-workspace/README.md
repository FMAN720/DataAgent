# Agent 会话工作区验收

2026-11-04。用户提供 Claude Code / Cowork 截图，要求界面具有 Agent 的会话式布局。本轮沿该参考重组工作区，使用原生 HTML、CSS 与 JavaScript，没有新增依赖或更换模型。

## 交付行为

- 深色会话侧栏展示真实历史分析，可直接恢复，数据管理收在次级入口。桌面可收起侧栏；手机使用支持焦点约束、Escape 关闭的抽屉。
- 新建分析时，居中的提问框是主操作；示例仅填入问题。输入区的“添加数据”连接表格上传、文档上传与图片/扫描件核对。
- 开始分析后，消息区独立滚动，底部输入框可连续追问。用户向上阅读时不强制滚回底部，可主动“回到最新”。
- 执行列表消费后端实际 SSE 事件，保留工具未完成状态；不显示模型推理文本，不虚构进度。完成或停止后收起执行摘要，审查状态与 E 编号记录仍可核对。
- Markdown、金额字符串、文档来源、上传确认、图片识别外发同意、历史快照与导出语义保留。指南与文字文档改为当前的“发送”和左侧“最近分析”入口。
