## 使用

本轮验收服务在 <http://127.0.0.1:18080/>，仅绑定本机。进入“分析对话”→“历史分析”，已有两份明确标注的合成演示。刷新后进入“分析对话”可恢复上次会话。浏览或导出现有报告不会调用模型；提交新分析会使用用户已有模型配置。

1. “合成演示：11月至12月各区域净销售额对比”：分组对比和正负贡献，可切换图表。
2. “合成演示：月度有效订单数趋势”：12 个真实查询观测点，原始 SQL 未提供单位，图中如实标注单位未声明。

两份演示来自项目固定种子业务库，直接执行工具，回答为确定模板，明确标注“未调用聊天模型”。不是用户上传资料，也不是付费模型评测。审查状态为未执行。演示记录写入两条独立会话保留供体验，没有改动业务数据。

只读生成演示（默认不写历史）：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m eval.delivery_offline --out reports/delivery-round2/demo-preview.json
```

增加 `--persist` 会新建两条演示会话，请按需要使用，重复执行会增加记录。脚本仅允许项目专用本机数据库，并校验已知演示总量。无需调用 DeepSeek 或 BGE-M3。

## 实现与数据流

`AgentOrchestrator` 开始一轮时读取 PostgreSQL 中的可信上下文。已有持久化会话优先使用它的可信近期问答，避免 Redis TTL 到期后遗忘；来源和条件以数据形式提供，新问题优先，数值必须重新查询。通用 `run_sql` 不推测业务语义。

工具执行和审查完成后，`app/analysis/artifacts.py` 从成功工具输出生成表格、图表及候选条件。`archive.py` 将完整响应写入现有 `Conversation/Message` 表：assistant Message 的 JSON 元数据保存不可变快照，Conversation 元数据保存可信条件、有限近期上下文和版本。写库通过线程执行，避免同步驱动阻塞事件循环。使用现有应用账号，与业务只读查询账号分离；无 DDL。

同一轮的 HTTP、SSE final、历史读取和导出使用同份响应。`trace_id` 同时标识报告；重复保存同一个 ID 返回原快照。保存时短事务锁定会话并比较请求开始时的版本，只有可信且版本相符的一轮更新条件。较早请求仍归档，返回未更新条件的提示。清空会话推进版本并清除可信上下文，防止在途旧请求恢复旧条件，报告保留。

前端只在 localStorage 保存上次会话 ID；正文从服务端读取。历史切换处理过期响应，恢复期间禁止提交；新建会话使在途恢复失效。原有工作台和视觉系统保持不变，没有图表框架、CDN 或远程字体。

## 接口和配置

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | `/api/v1/conversations?limit=30` | 最新会话；上限 50 |
| GET | `/api/v1/conversations/{session_id}?limit=50` | 已确认条件、版本、最近报告；上限 100 |
| GET | `/api/v1/analyses/{report_id}` | 保存的完整响应 |
| GET | `/api/v1/analyses/{report_id}/export?format=md` | Markdown，包含结果、限制、工具证据 |
| GET | 同上 `format=xlsx` | 元数据、所有结果表、完整查询证据 |
| GET | 同上 `format=csv&table_id=result-1` | 选定实际结果表及报告/口径元数据 |

`ANALYSIS_HISTORY_ENABLED` 默认 true，现有 PostgreSQL 配置由 `.env.phase2` 提供。启动时探测现有表；无可用存储时历史功能关闭，原有最小查数模式仍可启动。已启用的历史存储运行中失败时，就绪检查返回 503，模型调用前读取失败也返回 503。写入未确认则保留答案、标记 `archive_status=unconfirmed` 并隐藏导出，不自动重试付费调用。单份归档有效负载限制 2,000,000 字节，超出同样明确提示未确认保存。

## 数值与导出

- 表格与导出保留原始小数字符串，图表浮点数仅用于定位；大于 JavaScript 安全整数范围的观测不绘图，仍保留表格。
- 对比贡献仅在分项和独立总量核对通过后绘制。贡献表示统计拆解，不证明业务因果；比例贡献用百分点。
- 通用 SQL 结果需至少两个有效观测才生成图；时间趋势首列必须是唯一 ISO 日期/月，图按日期排序，原结果表保留查询顺序。不填补缺失观测。部分/截断结果不绘图。
- CSV 使用 UTF-8 BOM；对危险单元格前缀防公式注入，普通负数不受影响。若让 Excel 自动推断 CSV 类型仍可能损失长数字精度；需保真时选 XLSX。
- XLSX 单元格以文本保存，保留大整数和小数，不包含公式；清理 XML 非法控制字符，长文本拆为续行。
- Markdown 转义 HTML、链接和图片语法，工具证据使用安全代码围栏。导出读取保存快照，不重新计算，不发送内容到第三方。

## 当前边界

- 仍是本机单用户工作台，未实现登录、租户隔离、历史权限或保留期限管理；本轮没有把接口公开到外网。
- 只有本轮完成后的响应自动归档，已有 Redis 老对话不会追溯补成报告；中途取消或进程退出前未完成的响应不算已完成报告。
- 界面默认展示最近 30 个会话和选中会话最近 50 次报告，暂未做无限滚动或更早历史翻页。
- 结构化条件来自固定指标、准备分析、周期对比和数据体检工具；自由 SQL 不自动推断指标、单位、筛选或因果。默认指标口径与用户追加地区/渠道限制在界面分开说明。
- PostgreSQL 提供可信历史，Redis 仍按已有配置用于近期会话；Redis 故障时不静默切换内存模式。模型分析耗时目前不包括归档和下载耗时。
- 没有 PDF 报告、图表图片导出、OCR 或图片理解；这些不属于本轮。下一轮图片数据接入需要独立确定方案，涉及下载安装和外部付费调用时继续先征得用户同意。
- Impeccable 启动器此前未成功运行，已告知并直接读取项目上下文；未下载组件、未跑 detector。局部扩展依 `new-work.md` 不运行 concept-seed；未生成批准 comp 或 QUALITY BAR 卡，不宣称做过这些检查。
