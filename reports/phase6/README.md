## 实现内容

| 任务 | 实现 |
| --- | --- |
| 口径确认 | 新增 prepare_analysis，确认指标、数据来源、单位、维度、两个周期、筛选与默认假设；缺少条件时返回澄清问题，不擅自补数字或日期 |
| 澄清控制 | 同批出现口径确认和 SQL 时，先确认口径；缺少条件或参数错误则不执行同批其他工具。多个口径不能在同一批任意选一个。澄清问题保留在会话，可继续补充条件 |
| 变化拆解 | 新增 compare_periods，使用分组 SQL 和独立总量 SQL 的真实返回值计算增减及贡献；模型不能通过参数直接提交业务数值 |

| 可加性检查 | 分项分别核对基期和当期总量；比例检查两个周期的分子与分母。绝对差异容忍度为 0.000001，不随总量放大。口径不一致则不给贡献值 |
| 下钻约定 | 每次按一个维度拆解；继续下钻时两个 SQL 使用相同父级条件并记录 filters。不同维度的贡献不能相加 |
| 数据与资料解释 | 分析与规划提示要求先确认数据变化，再查同期资料，分别说明事实、资料解释、待验证假设；核对周期、单位、口径与来源，禁止凭相似度或上传新旧选择结论 |
| 逐项证据 | 审查返回 claim、supported/conflicting/insufficient、E 编号和理由；编号必须来自完整纳入审查且执行成功的实际工具记录 |
| 审查降级 | 审查证据按完整记录封装，不再默默截取 SQL 或结果尾部；超出预算、输出损坏或缺少逐项审查时明确标记 unavailable。仍最多修正一次 |
| 会话保护 | 最终审查 failed/unavailable 的答案仍返回供核对，并显示限制，不作为可信事实写入后续会话；主动关闭审查仍保留原先行为 |
| 界面 | 展示口径、筛选、假设、整体对比、分组贡献、冲突提示和逐项证据；SSE final 补齐 session_id 和完整 steps，E 编号与步骤顺序一致 |

普通查数、表结构问答和寒暄不强制填写两个周期。只比较整体时，维度可填“整体”。prepare_analysis 的使用由分析提示引导；缺少条件后的停止由代码执行，不能声称已用规则识别所有自然语言歧义。

## 计算规则

可加指标（例如同口径净销售额、订单量）：

```text
分组变化 = 当期值 - 基期值
整体变化 = 当期独立总量 - 基期独立总量
贡献占比 = 分组变化 / 整体变化 × 100%
```

贡献是有符号的。增减相互抵消时可能出现负贡献或超过 100%；整体变化为零时不计算贡献占比。基期为零或负数时不定义增长率，保留绝对变化。新增、消失分组应在 SQL 条件聚合中保留；NULL 数值和空数据不会被工具偷偷变成零，SQL 须明确处理。

退款率等比例使用总分子 / 总分母，不能平均分组比例。以 q 表示组内比例，w 表示分母权重，工具用对称分解：

```text
组内变化贡献 = (q当期 - q基期) × (w当期 + w基期) / 2
结构变化贡献 = (w当期 - w基期) × (q当期 + q基期) / 2
合计贡献 = 两项之和
```

输出乘以 100，单位为百分点。新增或消失分组采用可观察时期的组内比例，变化归入结构项；至少一个周期总分母为零时，不计算完整比例变化与贡献。rate 仅支持分子不超过分母的比例，客单价不能套用此规则。

计算使用 Decimal，结果以十进制字符串返回，重复小数最多八位；工作台贡献百分比展示两位、百分点展示四位，可能存在舍入尾差。不会把大整数转换为浏览器浮点数再格式化。

核对使用全部返回分组；展示最多八组及“其余分组（合计）”。查询已被行数上限截断时，直接拒绝计算。日期左闭右开，两个周期不能重叠；周期天数不同时提示未做日均调整。

## 边界与下一轮

1. 工具校验数值、可加性和快照一致性，不能通用证明模型写的 SQL 语义、JOIN 粒度、独立总量的独立性或 scope 标签都正确。相同错误也可能同时出现在两条查询中；仍须结合表结构、口径与审查核对。
2. 两个 SQL 没有截断且分项合计匹配，不等于已证明所有业务分组均被正确覆盖；例如遗漏的增减刚好抵消，单靠求和无法识别。暂无通用 SQL 语义解析器或因果推断框架。
3. 逐项语义支持、文档矛盾判断和自然语言澄清仍依赖模型。代码拒绝无效证据编号、损坏证据和不完整审查，但不能仅凭模型返回 supported 就证明覆盖了所有关键结论。
4. 统计贡献不是因果证明，资料计划也不是活动实际执行证明。未实现实验设计、干预评估或自动优惠分摊；品类明细与净销售额不一致时停止贡献，而不是偷偷改口径。
5. 无答案与冲突场景目前通过脚本模型测试协议，真实最终回答评测待第七阶段。现有 llm_calls/usage 仍不含规划和审查，不能当完整费用。
6. 本轮不扩展生产鉴权、多租户、Redis 会话、图表生成或长期任务调度，避免扩大当前范围。
