THESIS: configure one's own model services without memorizing model identifiers. OWN-WORLD: inherited charcoal surfaces, system sans and restrained leaf-green actions. STORY: choose purpose, provider/address and Key, explicitly fetch models, select, optionally test, save that purpose. FIRST VIEWPORT: one purpose and one form at a time with three compact purpose controls. FORM: incumbent dialog, native selects, existing labels, feedback and keyboard focus.

Chat, vision/OCR and embeddings have independent credentials, enabled state and runtime snapshots. Preserve existing chat settings and other-purpose drafts. Clear only the selected purpose with two-click confirmation. No environment-Key fallback for web features; no secret returned, browser-persisted or included in history. Retain 320px reflow, usable form scrolling and close/focus behavior.
