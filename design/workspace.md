# 数据分析 Agent 会话工作区

## Scope

Route `/`，Operate 模式。用户明确要求按所提供 Claude Code / Cowork 截图重做 Agent 布局，2026-11-04 继续完成。以该具体参考作为结构方向，code-led 实现；不复制 Claude 品牌，不发明未实现的模型切换、计划审批或任务调度。沿用原生 HTML/CSS/JavaScript，无新增依赖、远程字体或框架。

## Direction contract

**THESIS**：让用户像与 Agent 协作一样发起任务、看见执行进展、核对结果并持续追问。

**OWN-WORLD**：安静的深色分析对话。炭黑会话侧栏、暖深灰画布、略高一层的输入区，浅绿用于发送、选中及状态，品牌图标保留数据柱形。系统无衬线字体承载工具界面，等宽仅用于代码与证据编号。

**STORY**：左栏是真实历史分析与数据入口。新建时居中的欢迎语和提问框是主体，示例只填入问题，主动提交才分析。执行中正文展示简短状态；完成后在同一会话流呈现 Markdown 答案。后端实际 SSE 事件、审查、图表和 E 编号证据从该回答的“分析详情”按需打开，用户在底部输入框继续追问。

**FIRST VIEWPORT**：桌面侧栏 264px（窄桌面 236px，宽屏 280px），主区只有轻量顶栏和居中的 760px 提问区。无管理后台面包屑与重复页面大标题。空首页留白；对话开始后让消息区独立滚动，底部输入区持续可见。数据来源与“添加数据”连接真实上传与扫描面板。手机使用可关闭、可键盘操作的侧栏抽屉。

**SIGNATURE INTERACTION**：从居中首页切入任务对话；真实工具事件进入详情中的执行记录，运行时打开可查看，完成后收起为摘要。滚动阅读旧回答时不强制跳到底部，“回到最新”恢复跟随。历史切换、停止与新建均使用原有会话语义。

**QUALITY BAR**：第一眼识别为会话式 Agent；历史能继续，输入框可持续追问；失败的工具记录与未完成审查在详情中保持可达，不能以动效或颜色假装成功。菜单、移动抽屉、数据详情和指南不互相吞掉点击或抢焦点。数字字符串、外发同意、Markdown 安全策略保持原义。

**FINISH**：桌面、参考图宽度、1280px、390px 与 320px；空首页、运行、停止、历史、完成回答、来源索引、上传、扫描与指南均验证。真实鼠标和键盘操作，本机 Chrome 独立配置；离线合成聊天与上传响应不产生模型费用或持久数据。完成独立审阅并将实际令牌记录至 DESIGN.md 与 `.impeccable/design.json`。

## 个人 API 与详情扩展（2026-11-04）

延续当前深色 Operate 界面，不更换视觉系统。用户要求各自本机配置自己的 API，并明确否定将审查、E 编号、结果表和导出堆在回答正文内。新增左侧“API 设置”及未配置提示；设置使用原生 dialog，560px 宽、16px 圆角、现有配色，保存与会产生调用的连接测试分开。Secret 输入只在填写时存在，保存和关闭后清空，不向浏览器持久存储或回显。

每条回答仅保留安全渲染的答案和一个“分析详情”入口。原有执行、审查、图表、数据、来源、导出和 SQL 示例功能在右侧复用；桌面详情栏 440px，≤1380px 改为宽度不超过 480px 的覆盖抽屉，手机不撑宽正文。默认不展开，历史与运行状态使用同一路径；关闭返回原回答，查看来源后可返回详情，新建会话关闭旧详情。

本轮质量契约：未设置时不发起分析或回退 Key；保存不调用模型，连接测试须主动点击；修改仅作用于下一请求，正在执行的请求保留自己的配置快照；正文没有技术元信息节点；详情中失败记录、来源与导出保持可达。验证 1440/1280/390/320px、设置保存/清除/重载、草稿、历史、取消和来源回程，使用离线模拟凭据与响应，不消耗真实 API。
