# Markdown 与上传入口修复验收

2026-11-03。结论：本次修复范围通过。

- 原因：主工作区与导航按钮共用了 `data-view`，通用点击监听器因此绑定到主工作区。上传、图片及证据操作冒泡后触发切页，面板立即收起。主区改为 `data-active-view`，事件与导航状态更新均限定到 `.nav-item[data-view]`。
- 回答原先写入纯文本段落。现在使用本地、无依赖的 DOM Markdown 渲染，覆盖加粗、列表、标题、引用、表格与代码，新回答与历史恢复共用。HTML 保持文字，不加载模型提供的图片，只允许 HTTP(S) 链接；金额字符串不进行数值转换。
- 35 项前端测试通过，包括用户截图格式、恶意 HTML/链接、超长输入、表格转义及导航冒泡回归。47 项文档、API、图片相关 Python 测试通过。JavaScript 语法检查与 `git diff --check` 通过。
- 内置预览连续两次快照超时后，改用已安装 Chrome 的独立无头配置验证。通过真实鼠标事件打开表格、文档和扫描面板，确认三个文件选择窗口均能打开，文件名更新、提交及错误反馈均有响应；上传请求由本地模拟错误响应拦截，不写入持久数据。历史和流式回答采用明确标注的合成内容，未调用模型。
- 已查看桌面与手机截图。1440、1280、390、320px 均无页面横向溢出；代码块局部滚动，列表、加粗与表格层级清晰；E 编号仍能展开并聚焦对应记录。原有导航、色彩和单列阅读布局保留。
