# 配置自己的模型

打开左侧“API 设置”，在“聊天分析 / 图片与 OCR / 向量检索”之间选择。每种用途独立保存接入地址、模型和 Key；可以使用同一家供应商，但要分别填写或主动粘贴自己的 Key。

## 获取和选择模型

1. 选择供应商。DeepSeek、硅基流动、OpenAI 预设会填写 API 基础地址；其他兼容服务选择“自定义”。填写的是 API 地址，不是官网，也不是完整的 `/chat/completions` 请求地址。DeepSeek 的官方接入地址为 `https://api.deepseek.com`，参见[官方说明](https://api-docs.deepseek.com/quick_start/agent_integrations/)。
2. 填写此用途的 API Key。已保存时可留空保留；换接入地址必须重新输入，其他用途的 Key 不会被自动借用。
3. 点击“获取模型”，从供应商返回的模型目录选择。此操作只请求 `GET {基础地址}/models`，不测试推理，也不保存配置；列表仅表示供应商返回的模型，不保证当前账户拥有全部权限或模型适合所选用途。
4. 供应商不提供模型列表、返回空列表或权限不足时，界面保留当前填写，并可勾选“手动填写模型名称”。地址错误、Key 失效、限流和网络故障会显示对应提示，不自动重试。
5. 可主动测试，再点击“保存此用途”。保存只写本机配置；测试可能计费，具体外发内容见按钮上方说明。切换用途会保留本次窗口中其他用途尚未保存的输入；关闭窗口会清除所有未保存的 Key。

## 三种用途

| 用途 | 应选择的模型 | 测试发送的内容 |
|---|---|---|
| 聊天分析 | 支持工具调用的聊天模型 | 一次不含业务数据的工具调用请求 |
| 图片 / OCR | 支持图片输入及结构化转录的兼容聊天模型 | 一张只包含 `TEST` 的合成图片，核对图片输入与转录格式 |
| 向量检索 | 文本向量模型，不是聊天或重排序模型 | 一段短测试文字，读取实际返回的向量维度 |

OCR 当前支持 OpenAI 兼容的图片聊天接口，不是任意专用 OCR HTTP 协议。图片和向量服务需要 HTTPS，本机回环服务可使用 HTTP。保存图片模型后，还要在每次实际识别前勾选同意发送所选页面；保存设置不会自动识别。

DeepSeek 官方接口的聊天测试与分析默认使用非思考模式进行工具调用。能获取模型但测试失败不等于 Key 无效：HTTP 400 表示请求参数被拒绝，401 为认证未通过，402 为余额不足，403 为权限限制，429 为限流或配额问题。界面会显示供应商状态类别，网络和超时也单独提示；错误不会回显供应商原始正文或 Key。修复说明见[连接测试兼容记录](../../reports/deepseek-connection/README.md)。

## 启用向量检索和切换模型

测试向量模型后会自动填写实际维度，也可按供应商文档填写。勾选“启用向量检索”并保存后，新上传文档会发送到自己配置的服务建立索引，可能计费；未启用时仍可用本地关键词检索。

模型、接入地址和维度共同参与向量版本标识。更换后，旧向量保留，查询不与新模型混用。打开现有文档详情，若提示索引需要重建，可点击“使用当前模型重建索引”；该动作会发送文档内容并可能计费。保存配置本身不批量重建、不测试模型。已经开始的操作固定使用开始时的配置，下一次操作使用新配置。

## 本机保存和兼容

聊天、图片、向量配置均存于当前用户私密目录的 `model.json`，不写入项目或浏览器存储。Windows 的每个 Key 使用当前账户 DPAPI 加密；其他系统使用私密文件权限。接口只返回是否已保存，不返回 Key。旧版聊天配置仍可读取，首次保存任何用途时升级为多用途格式；清除只针对当前用途，需再次确认，其他用途保留。

网页三种用途都不读取开发者 `.env` 中的模型 Key。旧 `.env` 的视觉和向量参数仍可供离线脚本直接构造客户端，工作台请在本窗口独立配置。供应商模型目录不持久缓存，重开或需要刷新时可再次获取。

对应接口：`GET/PUT/DELETE /api/v1/model-settings?purpose=chat|vision|embedding`；`POST /api/v1/model-settings/models?purpose=...` 接收地址和可选新 Key；`POST /api/v1/model-settings/check?purpose=...` 使用合成材料测试，不保存。省略 purpose 保持原聊天接口行为。
